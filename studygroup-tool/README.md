# Study Group 自动提交工具

从 Google Sheets 自动批量提交学生咨询表单到 Study Group。

---

## Google Sheet 格式

| A 列 | B 列 | C 列 | D 列 | E 列 | F 列（自动） | G 列（自动） |
|------|------|------|------|------|------------|------------|
| 名 (First Name) | 姓 (Last Name) | 邮箱 | 手机号 | 意向课程 | 提交状态 | 提交时间 |

---

## 安装步骤

1. 打开你的 Google Sheets
2. 点菜单 **扩展程序 → Apps Script**
3. 删除默认代码，把 `Code.gs` 的内容全部粘贴进去
4. 点 **保存**（Ctrl+S）
5. 刷新 Google Sheets 页面
6. 菜单栏会出现 **📋 Study Group 提交工具**

---

## 找到 API 地址（重要！）

`Code.gs` 里的 `ENDPOINT` 目前是估计值，需要你确认真实地址：

1. 用电脑 Chrome 打开 Study Group 表单页面
2. 按 `F12` → 点 **Network** 标签
3. 勾选 **XHR** 或 **Fetch** 过滤器
4. 填写表单并提交
5. 找到出现的 POST 请求，右键 → **Copy → Copy as cURL**
6. 把这段 cURL 发给我，我帮你更新 ENDPOINT 和字段名

---

## 使用方法

### 手动提交
- 菜单 → **▶ 提交所有待处理行**（提交 F 列为空的所有行）
- 选中某几行 → 菜单 → **▶ 提交选中行**

### 自动提交（新增行自动触发）
1. 在 Apps Script 编辑器里点左侧 **⏰ 触发器**
2. 点 **添加触发器**
3. 选择函数：`onEdit`，事件类型：`电子表格 → 编辑时`
4. 保存

之后在 Sheet 里 A 列输入姓名，该行会自动提交。

## 字段默认值说明

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 咨询原因 | how_to_apply | 如何申请 |
| 性别 | female | 女 |
| 生日 | 2009-01-01 | 固定生日 |
| 国籍 | TW | 台湾（改 HK = 香港） |
| 留学目的地 | GB | 英国 |
| 学费支付 | self | 自费 |

如需改默认值，修改 `Code.gs` 顶部 `CONFIG.DEFAULTS` 里的内容。
